# nth-Order-Derivative-calculator
This code allows you to find the nth order derivative of just about most monomials in calculus provided all coefficients/exponents are integers or fractional, like the fraction x/y where x &amp; y are both values.

This project is free and open source, provided you state my name wherever you use it, state it has been modified when you do as well as license any works made from this code under the GNU General Public License v3.0.

If you wish to use this, clone the repository, make sure Python is installed on your device then run it via your terminal.
